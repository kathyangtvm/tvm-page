新手指南 · Beginner Route (Desktop App 版)

從零開始：
GitHub × Claude 桌面版新手上路

全程使用「GitHub Desktop」與「Claude 桌面版 App」（含內建的 Claude Code），幾乎不需要自己打指令。從註冊帳號開始，一路帶到用 GitHub Pages 把你的成果變成一個網站。

🖥️ 圖中 桌面 APP 代表這一步在 GitHub Desktop 或 Claude App 裡完成；網站 代表這一步必須打開瀏覽器到 GitHub 網站完成（目前只有 Pages 設定沒有桌面版功能）。
準備帳號 / 安裝 App 建立專案 開發循環（會重複） 上線 / 完成
1

註冊 GitHub 帳號網站

用 Email 建立帳號並完成信箱驗證。這是之後存放程式碼、發布網站的地方。

github.com/signup →
2

下載安裝 GitHub Desktop桌面 APP

下載後打開 App，點「Sign in to GitHub.com」，用步驟 1 的帳號登入即可 —— 不需要另外設定 Git 使用者名稱，App 會自動帶入。

desktop.github.com/download →
3

註冊 / 登入 Claude網站

用 Email 或 Google 帳號建立 Claude 帳號。之後所有程式碼都會請 Claude 幫忙寫。

claude.ai →
4

下載安裝 Claude 桌面版桌面 APP

安裝好打開後用步驟 3 的帳號登入，之後就能直接在桌面上跟 Claude 對話，不用開瀏覽器。

claude.ai/download →
5

安裝 GitClaude Code 需要

Claude 桌面版裡的「Code」分頁（也就是 Claude Code）需要電腦上先裝好 Git 才能運作。下載安裝後不用自己打指令，Claude Code 會自動幫你使用它。

git-scm.com/install/windows →
↓
6

在 GitHub Desktop 建立新 Repository桌面 APP

選單列點「File → New Repository」，輸入名稱，選一個本機資料夾存放，按「Create Repository」。

7

發布到 GitHub（Publish repository）桌面 APP

建立好後，畫面上會出現「Publish repository」按鈕，按下去。如果之後要用 GitHub Pages 做網站，記得取消勾選「Keep this code private」，設為公開。

↓
⟲開發循環

這四個步驟會不斷重複，直到你的網站做到滿意為止 —— 虛線邊框代表「這裡是迴圈，不是一次性流程」。

8

用 Claude Code 開啟專案資料夾桌面 APP

打開 Claude 桌面版，切到「Code」分頁，選擇步驟 6 建立的專案資料夾開啟。之後 Claude Code 就能直接讀寫這個資料夾裡的檔案。

9

描述需求，讓它直接改程式碼

用一般中文告訴 Claude Code 你想做的網頁功能或想修的問題，它會直接在資料夾裡新增/修改檔案並存檔，不用你自己複製貼上。

10

提交變更（Commit）桌面 APP

回到 GitHub Desktop，會看到剛剛的檔案變更，輸入這次改了什麼的簡短說明，按「Commit to main」。

11

按「Push origin」上傳桌面 APP

點畫面上方的「Push origin」按鈕，把剛剛的改動送上 GitHub。

↺
還想繼續改？ 回到步驟 8，跟 Claude Code 討論下一個功能，重複「開資料夾 → 改程式 → Commit → Push」。
小提醒：步驟 10、11 的 Commit 跟 Push，除了自己在 GitHub Desktop 手動按，也可以直接請 Claude Code 幫你操作，不用切換視窗。
↓
12

設定 GitHub Pages網站

這一步 GitHub Desktop 沒有對應功能，需要打開瀏覽器：進到你的 Repository 頁面 → 上方「Settings」→ 左側「Pages」。

在「Build and deployment」底下，Source 選「Deploy from a branch」，Branch 選「main」、資料夾選「/(root)」，按「Save」。

13

打開你的網站檢查成果

存好後等 1–2 分鐘，重新整理 Pages 設定頁，最上面會出現網站網址，格式通常是：

https://你的帳號.github.io/repo名稱/

打開它，看到你的網頁 —— 恭喜完成第一次「寫程式 → 上傳 → 上線」的完整循環！

卡住的時候

  • GitHub Desktop 或 Claude Code 出現看不懂的錯誤訊息時，截圖或複製文字貼給 Claude，請它幫你解讀並告訴你下一步該按什麼。
  • 忘記剛剛做到哪一步也沒關係，直接問 Claude：「我卡在哪個步驟，接下來該按什麼？」
  • 之後每次改完網頁，只要重複「開發循環」（步驟 8–11），GitHub Pages 上的網站會自動跟著更新，不需要重新設定 Pages。
  • 如果不想切換到 GitHub Desktop，也可以請 Claude Code 直接幫你 commit、push，甚至新開一個 branch，但一開始建議先手動按過一次，熟悉畫面上每個按鈕的作用。
